# Configurational Complementarity

The project reports condition-pair co-occurrence in sufficient configurations as configurational complementarity.

This does not establish economic complementarity or a causal interaction effect. It only shows that conditions repeatedly appear together in sufficient configurations under the selected calibration and thresholds.

The pipeline writes `complementarity_pairs.csv` with:

- source;
- condition pair;
- polarity of each condition;
- pair type;
- number of sufficient terms where the pair appears.

Interpret these diagnostics alongside sensitivity and regional results.
