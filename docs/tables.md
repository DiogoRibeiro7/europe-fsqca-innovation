# Tables

Scientific tables must be generated from code, not manually copied into the manuscript.

Use `write_generated_table` to write a CSV table and adjacent metadata JSON. Metadata records:

- generating function;
- source dataset;
- calibration specification;
- QCA specification;
- reproducible build identifier;
- generation timestamp.

The empirical table set should cover sample composition, variable mapping, construct definitions, calibration anchors, descriptive statistics, necessity, truth tables, solutions, regional comparison, portability, country diagnostics, sensitivity, robustness, and Python-R validation.
