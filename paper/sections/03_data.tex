\section{Data and Measurement}

The empirical analysis will use harmonised World Bank Enterprise Survey
microdata for European Union firms. This section must report the exact release,
survey years, country samples, exclusions, missing-data treatment, source
question wording, and construction of each raw analytical construct.

\subsection{Data provenance}

The raw WBES files are not stored in the repository. The empirical run must cite
the source release recorded in \texttt{data/manifest.csv} and the
release-specific mapping recorded in \texttt{configs/wbes\_variable\_map.yml}.

\subsection{Sampling design}

Report the sampling weight variable, the stratification variables, the fieldwork
year by country, and the resulting weight concentration and effective sample
size. State which estimand the headline results use and why.

\subsection{Analytical samples}

Report the inclusion rules for the primary sample and for the management
extension, together with the establishments and weight mass surviving each rule.
The management module is administered to larger establishments, so the extension
sample describes a different population and is analysed separately.
