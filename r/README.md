# R Validation Environment

The R workflow is an independent cross-check for QCA outputs generated by Python.

## Check Local Packages

```bash
Rscript r/setup_renv.R
```

This reports whether `renv` and `QCA` are available. It does not install anything.

## Install Packages

```bash
Rscript r/setup_renv.R --install
```

This initializes `renv` when needed and installs `QCA` from CRAN. Commit an `renv.lock` file only after package versions are installed and verified locally.

## Run Cross-Check

```bash
Rscript r/qca_crosscheck.R \
  results/main/calibrated_memberships.csv \
  INN \
  DIG,HC,FIN,INT,MGT,EXTK \
  results/r_validation
```

The calibrated CSV must come from the Python pipeline. Do not run the R cross-check directly on raw WBES files.
